About

Architecture-first.
Pragmatic always.

I'm a backend engineer who believes clean architecture is not a luxury — it's the foundation of maintainable systems. Every project I take on starts with understanding the domain, identifying constraints, and designing a system that can evolve gracefully.

I build backends using Java (Spring Boot) and PHP MVC, and I'm comfortable working on the frontend when needed. I've shipped projects ranging from CMS platforms and e-commerce systems to real-time multiplayer games and AI-driven learning tools.

I care deeply about performance, security, and code that a future engineer can actually understand. Not just code that works today.
