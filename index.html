About

Architecture-first.
Pragmatic always.

I'm a backend-focused engineer who believes clean architecture is not a luxury — it's the foundation of maintainable systems. Every project I take on starts with understanding the domain, identifying constraints, and designing a system that can evolve gracefully.

My core work lives at the intersection of Java / Spring Boot and PHP MVC backends, with a healthy appreciation for the frontend layer. I've built everything from CMS platforms and e-commerce systems to real-time multiplayer games and AI-driven learning platforms.

I care deeply about performance, security, and code that a future engineer can actually understand. Not just code that works today.

01
Clean Architecture Layered systems with clear separation of concerns. Domain logic never bleeds into infrastructure.
02
Security by Design RBAC, JWT, proper auth flows — security isn't an afterthought, it's woven into the data model.
03
Performance Engineering Cache-aside strategies, normalized schemas, query optimization. Systems built for scale.
04
Pragmatic Delivery Production-ready output that balances ideal architecture with real-world constraints.
